# Food Delivery System

## Project Description

The Food Delivery System is an online system designed to make food ordering and delivery management easier and more efficient.

## Main Features

- Customer registration and login
- Browse food items
- Search and select food
- Place food orders
- Manage orders
- Online payment
- Track delivery
- Restaurant management
- Delivery management

## Project Objective

The main objective of this project is to develop a user-friendly system that allows customers to order food conveniently while helping restaurants and delivery personnel manage orders efficiently.
